<p class="MsoNormal" style="margin-bottom: 6.75pt; line-height: normal;"><span style="font-size: 10.5pt;">** <em>Staff Information article intended for internal purposes only and is not to be distributed to students/general public.</em> **</span></p>
<p><em> </em></p>
<p><span style="font-size: 10.5pt;">Where a student has not provided an Australian contact phone number and has not responded to email requests to update their contact details, TaSAC may temporarily enable international calls. This allows you to call the number listed in the student’s contact record. Only one call attempt is required.</span></p>
<p><span style="font-size: 10.5pt;">Based on this, the process is as follows:</span></p>
<ol>
<li><span style="font-size: 10.5pt;"><strong>Send a TaSAC referral</strong> - Send an email to TaSAC using the TaSAC referral template via the Email tab in CRM under the case.</span></li>
<li><span style="font-size: 10.5pt;"><strong>Explain the situation</strong> - In the referral, advise that the student is not responding to email, cannot be contacted via domestic phone, and request temporary permission to dial their international number.</span></li>
<li><span style="font-size: 10.5pt;"><strong>Await TASAC’s response</strong> - Follow the instructions provided by TaSAC.</span></li>
<li><span style="font-size: 10.5pt;"><strong>Make one call attempt</strong> - If TASAC enables international calling, call the student's international mobile number once.</span></li>
<li><span style="font-size: 10.5pt;"><strong>Finalise the case</strong> - If the student still does not respond or answer, complete the case and document all contact attempts and outcomes in CRM.</span></li>
</ol>
<p class="MsoNormal" style="margin-bottom: 6.75pt; line-height: normal;"><span style="font-size: 10.5pt;"><strong> </strong></span></p>
<p class="MsoNormal" style="margin-bottom: 6.75pt; line-height: normal;"><span style="font-size: 10.5pt;">TaSAC can be contacted via email at <a href="mailto:tasac@cqu.edu.au" target="_top" rel="noreferrer noopener">tasac@cqu.edu.au</a>.</span></p>
<p class="MsoNormal" style="margin-bottom: 6.75pt; line-height: normal;"><strong><span style="font-size: 11pt;">How to call overseas from Australia</span></strong></p>
<p class="MsoNormal" style="margin-bottom: 6.75pt; line-height: normal;"><span style="font-size: 10.5pt;">To call an overseas number from Australia, follow these steps</span><span style="font-size: 10.5pt;">:</span></p>
<ol>
<li class="MsoNormal" style="line-height: normal;"><span style="font-size: 10.5pt;">Dial <strong>0</strong> to access International Calls from Cisco</span></li>
<li class="MsoNormal" style="line-height: normal;"><span style="font-size: 10.5pt;">Dial <strong>0011</strong></span></li>
<li class="MsoNormal" style="line-height: normal;"><span style="font-size: 10.5pt;">Dial the <a href="https://www.telstra.com.au/phone-line/international-calling/international-dialling-codes" target="_top">country code</a> (e.g. 44 for UK, 977 for Nepal, 91 for India, 880 for Bangladesh)</span></li>
<li class="MsoNormal" style="line-height: normal;"><span style="font-size: 10.5pt;">Dial the area code, then phone number (remove the first 0 if the area code starts with 0)<br></span><strong>00011 + Country Code + (Area Code + Telephone Number)</strong></li>
</ol>
<p class="MsoNormal" style="margin-bottom: 6.75pt; line-height: normal;"><span style="font-size: 10.5pt;">You will also need the area code and the number of the person you are calling.</span></p>
<p class="MsoNormal" style="margin-bottom: 6.75pt; line-height: normal;"><strong><span style="font-size: 10.5pt;">Examples:</span></strong></p>
<ul>
<li class="MsoNormal" style="line-height: normal;"><span style="font-size: 10.5pt;">To call the UK landline number: 065 8XX XXXX, you'd dial the following from Australia:<br><em>0 0011 <span style="text-decoration: underline;">44</span> 65 8XXX</em></span></li>
<li class="MsoNormal" style="line-height: normal;"><span style="font-size: 10.5pt;">To call the US mobile number: 0884 8XX XXXX, you'd dial:<br><em>0 0011 <span style="text-decoration: underline;">1</span> 884 8XX XXXX</em></span></li>
<li class="MsoNormal" style="line-height: normal;"><span style="font-size: 10.5pt;">To call the Nepal mobile number: 0980 116 4865, you'd dial:<br><em>0 0011 <span style="text-decoration: underline;">977</span> 980 116 4865</em><br><br></span></li>
</ul>
